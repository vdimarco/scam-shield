Source code and synthetic test cases ↗

Observed test · 17 November 2026

We tested the warnings against archived pages.

In one fresh run, we tested the extension’s on-device screener on 80 archived page snapshots. The result can be a warning, an unsure answer, or an error; each matters.

40 scam pages

30 warned · 9 unsure · 0 marked safe · 1 timed out

40 legitimate pages

18 marked safe · 21 unsure · 1 false alarm · 0 errors

A separate, deliberately difficult set of 20 legitimate finance and cryptocurrency pages produced 3 false alarms, 16 unsure results, and 1 safe result. All 79 completed checks in the 80-page run reported on-device inference; none used the cloud. These archived pages were evaluated from extracted text and page features, not as a live-browsing accuracy estimate. Results can vary between runs. Read the method and full results ↗
